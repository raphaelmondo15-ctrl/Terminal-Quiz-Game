# TERMINAL QUIZ GAME

A simple terminal quiw game built using pure bash scripting.
This project reads questions from a separate file and calculates the user's final score based on correct anszers.

## How the quiz works

The game stars after the player entring his\her name
The game display 11 questions with 4 option each
The scores are store to follow up your evolution
the final score is display as %

Make the script executable:
chmod +x quiz.sh
